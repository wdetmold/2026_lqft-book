\chapter{The parameters of QCD: $\alpha_s$ and the quark masses}
\label{ch:strong-coupling-sf}

The Lagrangian of QCD has no free parameters beyond a coupling and one mass per
flavour, and none of them is an observable: each is defined only relative to a
renormalisation scheme and scale. Determining them is therefore not a test of
anything, but a prerequisite for every test --- and it is a problem the lattice
is uniquely suited to, because the same non-perturbative renormalisation
machinery delivers both the coupling and the masses.
