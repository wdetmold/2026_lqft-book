\chapter{Machine learning methods}
\label{ch:ml-methods}

Numerical lattice field theory is a very data rich environment and consequently there are many ways in which machine learning methods can be applied to improve calculations. In the LFT context, where the outcomes are defined by the underlying LFT rather than specifics of its implementation, provable exactness to the underlying theory is a requirement for machine learning. This is a rapidly evolving field and this chapter presents a snapshot of some of the more foundational developments rather than detailing specific implementations and tools.
